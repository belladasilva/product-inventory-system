# Product Inventory System

A C++ console application I built to practice object-oriented programming through a simple product inventory and checkout system.

## What I worked with

- C++
- Object-oriented programming
- Inheritance
- Polymorphism
- Dynamic memory
- Input validation

## Features

- Create and manage different product types
- Store product information such as name, price, and barcode
- Use inheritance for different product categories
- Calculate product prices during checkout
- Validate user input
- Display product information using polymorphism

## Running the project

1. Open the project in Visual Studio
2. Build the solution
3. Run the application

## About

This is an older learning project I built while practicing C++ and object-oriented programming.
